# Auswahl des UML-Werkzeugs

**Gewähltes Werkzeug:** PlantUML

Mit PlantUML schreiben wir die Diagramme als einfachen Text. Aus diesem Text kann das Werkzeug automatisch das Bild erstellen. 
Der Text wird im Git-Repository gespeichert. So sieht jeder im Team, wer wann etwas am Diagramm geändert hat. 
PlantUML kann alles, was wir für Klassendiagramme brauchen und die Bilder lassen sich als PNG, SVG oder PDF speichern. 
Es ist kostenlos und läuft direkt im Browser unter plantuml.com/plantuml. Somit muss nichts installiert werden.
